# RPG 2D Arcade - Inventaire

## Lancer le jeu dans VS Code

1. Ouvre ce dossier dans Visual Studio Code.
2. Ouvre le terminal.
3. Installe Arcade :
   `pip install -r requirements.txt`
4. Lance :
   `python main.py`

## Contrôles

- TAB ou I : ouvrir/fermer l'inventaire
- ESC : fermer l'inventaire
- WASD : déplacer le personnage
- Clic sur une arme : l'équiper
- Clic sur les onglets : Arme / Équipement / Objet

L'épée utilise l'image fournie et est volontairement beaucoup plus grande une fois équipée.
